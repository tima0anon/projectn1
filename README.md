# Офлайн-шахматы

Android-приложение на русском: локальный Stockfish 16.1, выбор примерной силы и цвета, отмена хода, автосохранение, архив партий и экспорт PGN.

Сборка и проверки выполняются в GitHub Actions. APK и полный архив исходников публикуются в Releases после успешных проверок.

Сетевые разрешения в приложении отсутствуют. Интернет нужен только при сборке проекта.

Лицензия проекта GPL-3.0-or-later. Stockfish — GPL-3.0; chess.js — BSD-2-Clause. Тексты лицензий и исходники движка включаются в выпуск.
