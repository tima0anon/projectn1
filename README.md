# Офлайн-шахматы 2
Android 8+ (ARM64 и x86_64), русский интерфейс, полностью офлайн.

## Возможности
- Классические SVG-фигуры Cburnett, стандартные цвета доски, анимация и перетаскивание.
- Таблица ходов: отдельные столбцы белых и чёрных.
- Игра: Stockfish 16.1, приблизительный Elo 400–3000, выбор цвета, отмена хода.
- Обучение: тренер оценивает каждый ход, показывает изменение оценки, лучший вариант и сильный ответ соперника. После вашего хода игра ждёт кнопки «Продолжить». Можно переиграть ход.
- Практика: оценки каждого хода на доске и в таблице без пауз на подтверждение.
- Автосохранение, архив партий с оценками и режимом, экспорт PGN.

Пометки: лучший, отличный, хороший, неточность, ошибка, грубая ошибка, вынужденный ход, упущенный мат. Вычисляются полносильным Stockfish до и после хода (до 16 полуходов глубины, до 1.1 секунды на позицию). Время анализа и сила устройства влияют на результат. Сила тренера независима от Elo противника. Это собственная шкала приложения, не алгоритм Chess.com.

Оценка позиции приводится за белых: плюс — преимущество белых, минус — чёрных.
Разбор строится на изменении оценки и реальных вариантах движка. Клик по ходу открывает его сохранённое объяснение. «Показать ответ» рисует сильный ответ соперника на текущей доске.

## Установка
[APK и исходники](https://github.com/tima0anon/projectn1/releases/latest).
Версия 2 устанавливается отдельным приложением «Офлайн-шахматы 2», поэтому первую версию удалять не требуется. Её сохранения остаются в первой версии.

## Сборка
JDK 17, Gradle 8.9, Android SDK 35, build-tools 35.0.0, NDK 27.2.12479018.
```sh
bash scripts/build-engine.sh
# В полном архиве выпуска app/dev.keystore уже включён.
# При сборке из git можно создать стандартный локальный debug-ключ
# или получить общий development-ключ через scripts/setup-signing.sh.
gradle wrapper
gradle assembleDebug
npm install
npm test
gradle connectedDebugAndroidTest
```
В APK отсутствует разрешение INTERNET; интернет нужен только для получения зависимостей сборки. Прямые сборки подписаны development-ключом. Постоянный общий development-ключ включается в архив исходников и сохраняется в отдельном prerelease для последующих обновлений.

## Проверки
GitHub Actions собирает движок и APK, проверяет подпись и отсутствие INTERNET, запускает тесты правил/интерфейса, затем тесты приложения с настоящим Stockfish на Android 15. Выпуск публикуется после успешного прохождения.
