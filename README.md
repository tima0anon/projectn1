# Офлайн-шахматы
Минималистичное приложение на русском для Android 8+ (ARM64, x86_64).

- Встроенный Stockfish 16.1 с NNUE; интернет и аккаунт для игры не нужны.
- Примерная сила 400–3000 Elo, выбор белых, чёрных или случайного цвета.
- Отмена хода вместе с ответом движка.
- Автосохранение текущей игры, архив сохранённых партий и экспорт PGN через системный выбор файла.
- Полные правила: рокировка, взятие на проходе, выбор фигуры превращения, мат, пат, повторение, правило 50 ходов.

Рейтинг ориентировочный, не равен рейтингу аккаунта на шахматных сайтах. Ниже 1320 используются Skill Level и дополнительная вероятность ошибки.

## Скачать
Готовые APK и полный архив исходников находятся в [Releases](https://github.com/tima0anon/projectn1/releases).
Выпуск публикуется автоматически только после сборки, проверки подписи, тестов правил и теста приложения со Stockfish на эмуляторе Android 15.

## Сборка
Нужны JDK 17, Gradle 8.9 и Android SDK 35.
Установите через sdkmanager платформу android-35, build-tools 35.0.0 и ndk 27.2.12479018.
На Linux запустите:
```sh
bash scripts/build-engine.sh
gradle wrapper
gradle assembleDebug
```
Интернет используется при получении зависимостей сборки. В самом APK отсутствует разрешение INTERNET, все ресурсы и движок встроены. Версия 1.0 распространяется как подписанный debug APK для непосредственной установки, без Google Play.

## Проверки
```sh
npm install
npm test
gradle connectedDebugAndroidTest
```
