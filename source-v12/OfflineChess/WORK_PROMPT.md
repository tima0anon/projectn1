# Задание для режима Work — собрать APK OfflineChess 1.2

В приложении архив **OfflineChess-v1.2-complete-source.zip**. В нём существующий рабочий Android Gradle-проект с русскоязычными офлайн-шахматами. **Не переписывай приложение с нуля; доведи исходники до полностью проверенного APK**.

1. Распакуй ZIP, открой проект, настрой Android Studio / Gradle, JDK 17, Android SDK API 35, NDK r27c+ и совместимый Gradle 8.9. При отсутствии wrapper создай его.
2. Выполни `scripts/build-stockfish.sh`. Скачай официальный Stockfish, собери версию для `arm64-v8a`, включи NNUE-сети и упакуй исполняемый `libstockfish.so` в `app/src/main/jniLibs/arm64-v8a/`. Исправь скрипт при несовместимости с новыми Stockfish/NDK. Включи commit ID и GPL-лицензию. Не оставляй сборку только с резервным JS-движком.
3. Проверь Android Java UCI-мост: `uci`, `isready`, `UCI_LimitStrength`, `UCI_Elo`, `MultiPV=3`, `go movetime`, оценки матовых позиций, отмену анализа, восстановление процесса. Проверь слабые и сильные уровни компьютерного соперника.
4. Проверь на ARM64 Android все функции: классические SVG-фигуры, анимацию, выбор цвета/Elo, ход/отмену, режимы «Игра», «Практика», «Тренер», историю ходов, PGN, сохранение и восстановление партий.
5. Проверь разбор: две точности, семь классификаций, примерный рейтинг за партию, график, три лучших продолжения, стрелки, подробное объяснение и тактические мотивы. Проверь «Работу над ошибками»: позиция до неверного хода, выбор исправленного хода, подсказка, следующий ошибочный ход.
6. Проверь справочник из 52 дебютных линий: поиск по названию/ECO, показ на доске, переход по ходам, определение дебюта в текущей партии.
7. Запусти `node tests/rules.test.js`, `node tests/review.test.js`, `node tests/insights.test.js`, `node tests/ui-smoke.test.js`. Если есть Chromium/Playwright, проверь `python tests/browser_smoke.py`. Проверь UI на ширинах 360, 390 и 430 px, чтобы элементы не наезжали друг на друга. На реальном устройстве проверь офлайн-режим и отчёт после перезапуска.
8. Собери `app-debug.apk`, установи и проверь. Исправляй реальные ошибки, если возникнут. В конце предоставь **готовый APK и ZIP финальных исходников**, перечисли фактически выполненные тесты.

Никаких шахматных задач и интернет-игры. Никаких логотипов Chess.com; оценки и рейтинг отмечай как приближённые, а не оригинальный закрытый алгоритм Chess.com.
